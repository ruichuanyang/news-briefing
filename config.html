📰 晨报板块管理

在这里调整每日晨报的栏目、搜索词与时长。修改会直接写回仓库并自动生效。
⚠️ 保存 / 立即生成 需要你的 GitHub 个人访问令牌（PAT）。令牌仅保存在你当前浏览器本地（localStorage），只会发给 api.github.com，不会上传到任何第三方服务器。
需要一个具备 repo 权限的 PAT：GitHub → Settings → Developer settings → Personal access tokens → 勾选 repo。

① 访问配置

输入后点“保存令牌到本机”，之后每次打开会自动填入。

② 全局设置

按实测语速约 4.5 字/秒估算。想要 5 分钟填约 1350；想更长就调大。

③ 新闻板块

搜索词支持占位符：{date} = 今天（如 2026年08月25日），{short} = 月日（如 08月25日）。
